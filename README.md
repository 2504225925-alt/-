# 智慧养老服务平台

这是根据仓库中的项目方案书与要求，生成的智慧养老服务平台前端原型项目。目标是为养老机构、家庭用户与护理人员提供统一的健康管理、生活照护、安全监护和服务协同体验。

## 功能概括

- 养老机构总览与运营监控
- 老人健康档案与风险评估
- 生活照护、清洁、送餐、陪诊等服务管理
- 设备状态监测与报警中心
- 家庭关怀与通知协同
- 预约管理、排班调度和服务工单

## 目录结构

- `index.html`：主页面
- `styles.css`：全站样式
- `script.js`：交互逻辑

## 运行方式

直接在浏览器中打开 `index.html` 即可，或者在项目目录中运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 项目定位

该项目适用于：
- 养老院/社区养老服务中心运营管理
- 家庭智慧养老与居家照护支持
- 健康监测、应急响应及服务协同

## 说明

项目以响应式信息化管理平台为设计目标，体现 "智能、健康、安全、便捷、协同" 的养老服务理念。
