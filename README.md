# 智慧养老服务平台

面向智慧养老场景的响应式静态 Web 原型，提供机构管理端以及患者/家属服务端，用于展示健康档案、照护预约和运营管理等流程。页面中的人员、健康指标和运营数据均为演示内容，不接入真实医疗服务或身份认证系统。

## 项目简介

平台围绕“健康管理、生活照护、服务协同”提供两类使用界面：

- 患者/家属端：浏览健康概况与测量记录、查看照护安排、完成日常提醒、提交服务预约并查看演示工单。
- 机构管理端：查看老人档案、健康监测、服务工单、设备状态、报警信息及报表统计。

本项目是前端静态原型，不包含后端、数据库或真实业务接口。演示交互与数据不能用于真实医疗判断或紧急求助。

## 技术架构

- HTML5 多页面结构，使用语义化 HTML 表达管理端和患者端功能。
- CSS3 样式设计，管理端共用 `styles.css`，患者端共用 `patient.css`，登录页使用 `login.css`。
- 原生 JavaScript 实现交互逻辑；`script.js` 负责管理端和登录页交互，`patient.js` 负责患者端交互。
- 数据以演示数据为主，患者端预约和提醒状态会保存在浏览器 `localStorage` 中，便于本地体验。
- 项目通过静态 HTTP 服务器加载，不依赖后端服务。

## 页面导航

### 患者 / 家属端

- `login.html`：登录页面与患者/家属、管理者角色选择（仅页面跳转演示）
- `patient.html`：患者首页、健康概况、今日安排、常用服务和提醒
- `patient-health.html`：健康档案、趋势展示、测量记录和健康小贴士
- `patient-service.html`：服务预约、我的演示工单和帮助说明

### 机构管理端

- `index.html`：管理端运营总览
- `elderly.html`：老人档案
- `health.html`：健康监测
- `service.html`：服务工单
- `equipment.html`：设备管理
- `alarm.html`：报警中心
- `report.html`：报表统计

## 环境要求

- 现代浏览器（推荐 Chrome、Edge、Firefox 或 Safari 最新版）
- Python 3.8+ 可用于无需安装依赖的静态预览
- 可选：Node.js 18+ 与 npm，用于格式检查与启动项目内置静态服务器

网页运行无需配置 API 密钥、数据库或环境变量。项目没有 `.env` 配置要求；如后续接���真实服务，应通过独立的环境变量模板说明配置项，并避免提交密钥、真实患者信息或敏感数据。

## 安装与运行

### 方式一：Python 静态服务器

```bash
git clone https://github.com/2504225925-alt/-.git
cd -
python3 -m http.server 8000
```

Windows 可使用：

```powershell
py -m http.server 8000
```

浏览器访问 `http://localhost:8000/login.html`。

### 方式二：Node.js 开发服务器

```bash
npm install
npm run dev
```

默认访问 `http://localhost:8000/login.html`。

格式检查：

```bash
npm run format:check
```

格式化：

```bash
npm run format
```

## 代码规范与协作约定

- 源文件采用 UTF-8 编码、LF 换行和 2 个空格缩进，配置见 `.editorconfig`。
- HTML 使用语义化元素，并为表单控件提供可访问名称。
- JavaScript 以 `const` / `let` 方式编写，保持 Prettier 统一格式；DOM 操作时需考虑页面元素可能不存在的情况。
- CSS 按功能分块管理，避免影响其他页面。
- 提交前运行 `npm run format:check`，并使用清晰的提交说明。
