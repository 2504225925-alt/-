# 智慧养老服务平台

这是一个基于智慧养老/智慧医疗场景设计的前端项目，支持多页面管理后台展示，适用于养老机构运营、老人健康管理和智能服务协同场景。

## 当前版本

- 首页运营概览页
- 老人档案管理页
- 健康监测中心页
- 响应式布局与交互动画
- 适用于静态页面演示和前端原型评审

## 目录结构

- `index.html`：首页总览
- `elderly.html`：老人档案页面
- `health.html`：健康监测页面
- `styles.css`：全站样式
- `script.js`：页面交互动画

## 运行方式

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/index.html
```

## 项目定位

适合用于：
- 智慧养老平台演示
- 老年健康管理后台展示
- 养老机构运营监控
- 智能健康设备与服务协同演示

## 说明

该项目采用现代化信息化管理平台风格，强调“健康、安心、智能、温暖”的养老服务体验，便于后续扩展到登录页、病例管理、服务调度、系统设置等完整业务模块。
