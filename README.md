# 智慧养老服务平台

这是一个面向智慧养老/智慧医疗场景的 Web 应用型后台管理原型，覆盖 PC 端和移动端展示，适用于养老机构运营管理、老人健康档案、健康监测、设备管理和告警处理等业务场景。

## 当前版本

- 首页运营总览
- 老人档案管理
- 健康监测中心
- 服务工单管理
- 设备管理中心
- 报警中心
- 报表统计
- 登录页
- 响应式 PC / 移动端 Web 展示

## 目录结构

- `login.html`：登录页
- `index.html`：首页总览
- `elderly.html`：老人档案
- `health.html`：健康监测
- `service.html`：服务工单
- `equipment.html`：设备管理
- `alarm.html`：报警中心
- `report.html`：报表统计
- `styles.css`：全站样式
- `script.js`：交互逻辑与移动端菜单控制

## 运行方式

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/login.html
```

## 项目定位

适用于：
- 智慧养老平台演示
- 医养结合运营后台
- 老人健康管理系统
- 智能设备与告警中心管理
- 面向方案评审的前端 Web 应用原型

## 说明

该项目强调“健康、安心、智能、温暖”的养老服务体验，适合后续继续扩展为更完整的企业级后台系统，包括权限管理、消息通知、数据看板和更多业务模块。
